## Aturan pemakaian

- Jangan ubah warna, proporsi, atau tambahkan efek pada logo.
- Beri ruang bebas di sekeliling logo minimal setengah lebar lambang.
- Logo hanya boleh ditempatkan di latar yang kontras (putih atau hijau gelap).
- Sumber logo resmi dan versi vektor (SVG) masih ditunggu (`docs/DECISIONS.md` OQ-04).

## Kebutuhan ukuran (setelah ada file sumber besar)

| Pemakaian | Ukuran minimal |

| Header (layar retina) | tinggi 80 px (2×) |
| Open Graph / media sosial | 1200×630 px (komposisi, bukan logo mentah) |
| Favicon | 512×512 px, diturunkan menjadi 32/180/512 |
